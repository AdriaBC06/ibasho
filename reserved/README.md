# Reservado

Assets con licencia verificada que **no** se empaquetan en la app todavía: no
están en `pubspec.yaml`, así que no suman peso al build. Se guardan aquí para
usos futuros (otras apps o canales de Ibasho).

Autoría, licencia y origen de cada uno: `CREDITS.md`, sección «Reservado».
Si se mueve alguno a `assets/`, hay que añadirlo también a la pantalla de
créditos (`lib/core/credits.dart`).
